
# Cat App Frontend

## Описание

Это фронтенд приложение для загрузки и просмотра мемов и высказываний с котами. Пользователи могут делиться своими мемами и мыслями, добавляя теги и аватары.
Пользователи могут получать предсказания на главной страничке.

## Ссылка на продакшн

[https://cat-app-front.onrender.com](https://cat-app-front.onrender.com)

---

## Технологии

- React + TypeScript  
- Next.js  
- CSS Modules для стилизации  
- Axios для HTTP-запросов  
- Render.com для деплоя фронтенда  

## Фичи
- Загрузка мемов и высказываний — пользователь может добавить изображение с описанием, тегами и аватаром.
- Две вкладки контента — мемы и высказывания, между которыми можно переключаться.
- Превью аватара — при выборе файла для аватара пользователь видит его превью перед отправкой.
- Валидация форм — проверка обязательных полей перед отправкой (например, текст высказывания).
- Обработка ошибок и уведомления — показываются сообщения об ошибках и успешных действиях.
- Реализация загрузки файлов через FormData — для отправки изображений и аватаров на сервер.
- Использование Next.js с оптимизацией изображений через компонент <Image>.
- Интерактивные UI-элементы — вкладки, кнопки, формы, предпросмотр изображений.
- Возможность обсуждать посты и реагировать на высказывания других.
- Пользователи могут ставить оценки понравившимся фразам.
- На главной странице отображается случайное кото-предсказание при каждом обновлении.

## Локальная разработка

### Требования

- Node.js (версия 16 или новее)  
- npm или yarn  

### Установка и запуск

1. Клонируйте репозиторий:  
   ```bash
   git clone https://github.com/sofisofi01/cat_app_front.git
   cd cat_app_front
   ```

2. Установите зависимости:  
   ```bash
   npm install
   # или
   yarn install
   ```

3. Запустите приложение в режиме разработки:  
   ```bash
   npm run dev
   # или
   yarn dev
   ```

4. Откройте в браузере [http://localhost:3000](http://localhost:3000)
